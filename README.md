# Sunny 電子商務導論複習網站

- 92 題選擇題（六個單元），答案依原測驗截圖右側的「詳解」。
- 20 題簡答／填充題（由第一次作業五題延伸）。
- 章節練習、模擬考、錯題本、收藏題目、關鍵字背誦。
- 純 HTML、CSS、JavaScript，不需安裝套件或後端。

## 使用方式
將 `index.html` 與 `questions.js` 放在同一資料夾，直接開啟 `index.html` 即可使用。也可將整個資料夾上傳 GitHub Pages 靜態網站。

## 注意
文字以課程來源為依據，部分冗長選項為改善手機閱讀而精簡，非逐字校對版本。原始題目包含少數具時效性或可能有爭議的觀念與答案（如第五單元第10、18、25題及第六單元跨境法規）；本網站仍依當時教材答案判分。測驗進度及筆記存在目前瀏覽器 localStorage，不會跨裝置同步。
